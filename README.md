# Yusuf Ahmed Portfolio

Neu gestaltetes Portfolio auf Basis von Vue 3, TypeScript und Vite.

## Fokus

- editoriale One-Page-Struktur statt komponentiger Demo-Optik
- klarere Positionierung fur Websites, Shops und Frontends
- starke Typografie, warme Farbpalette und reduzierte Motion
- responsive Navigation und scrollbasierte Reveal-Effekte

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
